Matchup adjustments applied
This tool estimates probability from the games and matchup factors you enter. The matchup adjustments use reasonable football logic (defense strength, game script, weather, injuries, home/away, recent trend) but are not a statistically fitted or backtested model — treat the weights as directional, not precise. Small sample sizes (fewer than 5-6 games) make the underlying read unreliable regardless of adjustments. This does not access live sportsbook odds. Treat it as one input among many, not a prediction.
